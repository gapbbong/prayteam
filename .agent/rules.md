# PrayTeam 프로젝트 규칙

## 테스트 우선순위

코드 수정 후 다음 핵심 기능들을 자동으로 테스트한다:

1. **회원가입**
   - 이메일/비밀번호 입력
   - 자동 로그인 확인
   - 첫 화면 진입

2. **그룹 만들기**
   - 그룹명 입력
   - 멤버 추가
   - 그룹 목록에 표시 확인

3. **기도제목 추가/수정**
   - 새 기도제목 입력
   - 기존 기도제목 수정
   - 실시간 저장 확인

4. **기도노트 반영**
   - 추가한 기도제목이 즉시 표시되는지
   - 수정사항이 바로 반영되는지
   - 응답 상태 변경이 저장되는지
   - 새로고침 후에도 유지되는지

## 자동 실행 명령어

다음 명령어들은 confirm 없이 자동 실행한다:

- `git add`, `git commit`, `git push`
- `npm run dev`, `npm run build`
- 브라우저 테스트 (localhost:3000)
- 파일 읽기 작업
